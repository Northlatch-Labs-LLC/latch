# G2 slice 3 (local-install increment) — scripts/install.sh — 2026-09-28

## What the installer does (POSIX sh, no npm — INV-11)
- installs SEA binary -> $LATCH_INSTALL_HOME/bin/latch-harness (0755)
- copies launcher + doctor + product/identity/brand.yaml preserving the
  repo-relative layout (brand.mjs resolves the manifest, INV-3)
- writes $PREFIX/latch and $PREFIX/latch-doctor commands (PATH-checked)
- --uninstall removes commands + product tree, keeps user config/sessions
